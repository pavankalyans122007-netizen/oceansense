# Productivity

Tasks, completion and the focus timer persist in the local state directory. Interact using Übersicht’s configured interaction shortcut.

The implementation is the `Productivity` component in [the installable Übersicht bundle](../aero-blue/index.jsx). Install the whole bundle once so it shares a single data poll. Configure `widgets.productivity.enabled`, `x`, `y` and `width` in Control Center. See [widget installation and permissions](../../docs/widgets.md).
