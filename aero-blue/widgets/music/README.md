# Music

Apple Music track, artist, actual artwork when supplied, play/pause and next. Connect Music explicitly and grant Automation permission if desired.

The implementation is the `Music` component in [the installable Übersicht bundle](../aero-blue/index.jsx). Install the whole bundle once so it shares a single data poll. Configure `widgets.music.enabled`, `x`, `y` and `width` in Control Center. See [widget installation and permissions](../../docs/widgets.md).
