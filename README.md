# Ocean Sense · Aero Blue

[Aero Blue](aero-blue/README.md) is a native macOS Frutiger Aero customization toolkit: original wallpapers, crystal icons and cursor artwork, desktop widgets, and a SwiftUI control center with reversible user-level settings.

Start with the [project instructions](aero-blue/README.md). Development in a Linux cloud workspace does not modify your Mac; installation and macOS verification run locally on your Mac.
